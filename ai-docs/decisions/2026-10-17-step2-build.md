# Step 2 build rulings (2026-10-17)

Small rulings made while building, per the kickoff's "decide small rulings yourself, record each, flag it". Each
can be reversed.

1. **One evergreen unit for the plugin, not one per skill.** RESEARCH.md was already one file covering all
   three skills, and the skills share hw.py and the registry. The unit sits at the repository root (kind
   `plugin`, main README.md, pointer mode), as the evergreen plugin's own unit does. `evergreen.py init` kept
   RESEARCH.md. Interval: evergreen's default for `moderate` (30 days), not the 60 the synthesis proposed;
   `hw.py probe` covers endpoint moves between refreshes.
2. **Pack images go in `refs/`, not `references/`.** The kickoff said `references/`, but polywright's asset
   contract names the folder `refs/`; using its name makes every pack a valid polywright asset folder
   (`manifest.json` in polywright's shape plus a `historywright` block), which is what "the layout matches
   polywright's asset contract" asks for.
3. **hw.py is split into five stdlib files** (`hw.py` plus `hw_net`, `hw_dates`, `hw_sources`, `hw_check`) in the
   hub's `scripts/`, so each stays readable; `hw.py` is the only entry point.
4. **A generic `src` command over the registry** instead of one command per archive or museum: each registry
   entry with a JSON search carries a URL template, an items path and field paths, so adding a source is a data
   edit with a lint, not code.
5. **validate-pack accepts EDTF level 0 and 1 plus the level 2 set syntax** (`[a,b]`, `{a,b}`), because a
   disputed date must be a set or a range and level 1 has no set.
6. **DILA data: DILA's own zip first, its GitHub copy second.** Both are DILA's own publication under CC BY-SA
   3.0; the GitHub copy covers the certificate problem in R-20261017-27 and any outage.
7. **Keys are never printed or logged**: `keys status` says "set, ends ..xy"; OpenAlex and WHG keys travel in an
   `Authorization: Bearer` header; the fetch log and `src` output redact any `key=`, `api_key=`, `wskey=` or
   `token=` query value (registry sources that need a key in the URL, such as Europeana).
8. **The fetch log and page store are the "fetched and read" evidence.** `verify sources` fails a source whose
   URL is not in this HW_HOME's fetch log (`--any-url` relaxes it for packs built elsewhere).
9. **The source registry was transcribed by a subagent** from the four subject reports with each search
   endpoint live-tested; its note is [../research/2026-10-17-registry-build.md](../research/2026-10-17-registry-build.md).
