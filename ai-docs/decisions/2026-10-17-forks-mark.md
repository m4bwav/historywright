# Mark's answers on the three Step 1 forks (2026-10-17)

1. **Free keys: yes, where it can be automated or is easy.** OpenAlex was automated (the key was requested through the API and saved; Mark clicks the activation email). WHG needs an ORCID sign-in in the browser, so the page was opened for him. The process is written up for other users in [../notes/api-keys-setup.md](../notes/api-keys-setup.md). Product consequence: `hw.py keys` does the same for any user (`keys openalex --email` posts the request after the user says yes; `keys whg` opens the sign-in page and saves the token the user pastes; `keys status` checks each one). The README gets an "Optional keys" section from the note.
2. **East Asian era conversion: on-demand download, as recommended.** The licence question is settled: the DILA Time Authority data is CC BY-SA 3.0 Unported (COPYING.rst in github.com/DILA-edu/Authority-Databases; the DILA site's footer says CC BY-SA 2.5 Taiwan). Refinement: download DILA's own archive (`authority_time.2012-02.zip`, 1.34 MB, from authority.dila.edu.tw or the GitHub repo) and build the SQLite table locally in `~/.historywright/`. Do not use kltng/calendar_converter's prebuilt `calendar.db`: that repository states no licence (GitHub reports NOASSERTION) and has 2 stars. Keep kltng's design (JDN pivot, every match for an ambiguous era name, regnal-year parsing) and credit it. The built table is a CC BY-SA derivative: it stays on the user's machine, and attribution goes in the answer's source line and in the README. kltng's README notes Vietnamese years may be off by one near era boundaries and that DILA covers China 220 BCE–1912, Japan 593–1872 and Korea 56 BCE–1885.
3. **Paid sources: none.** Gated sources stay link-out only.
